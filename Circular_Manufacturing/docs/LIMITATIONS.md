# V1 Limitations

- Shipped numerical data are synthetic.
- Lifecycle cost/carbon factors are not externally calibrated.
- No realized cost, carbon or service benefit is claimed.
- External scenario bundles are schema-validated, not independently source-verified.
- The AI benchmark demonstrates a valid computational pipeline, not field generalization.
- The local HTTP server is not a replacement for an enterprise application gateway.
- Authentication/authorization are not implemented in the offline portfolio V1.
- Render/Docker assets are deployment-ready configuration; public production deployment remains a separate acceptance step.
- The recommendation is decision support and retains `human_approval_required = true`.
