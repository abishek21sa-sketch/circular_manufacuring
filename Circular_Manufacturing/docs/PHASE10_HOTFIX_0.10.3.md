# Phase 10 Hotfix 0.10.3 — Portable AI Runtime

Windows Python 3.14 / scikit-learn 1.9 exposed that estimator joblib files in
0.10.2 had been serialized under scikit-learn 1.8. The recovery classifier
contained a private compiled `_loss` object that could not be imported in the
new runtime, causing `ModuleNotFoundError: _loss` and `InconsistentVersionWarning`.

## Architectural correction

Phase-10 decision execution no longer deserializes packaged scikit-learn models.
The four synthetic-validation models are fitted deterministically in the current
runtime from versioned code and seeded synthetic benchmark generators, then
cached in memory for the process lifetime.

Persisted sklearn/joblib estimator binaries are not part of the portable release.
The release keeps JSON model evidence and the accepted prediction artifacts, while
runtime predictions/explainability are generated by the current-runtime model bundle.

This removes dependence on scikit-learn private pickle internals and makes clean
Windows execution compatible across supported scikit-learn minor versions.
