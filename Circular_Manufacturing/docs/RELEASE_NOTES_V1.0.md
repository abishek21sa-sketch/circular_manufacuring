# V1.0 Release Notes

V1.0 closes the development line from Phases 1–10 and adds the final enterprise/product layer.

New in V1:
- SQLite scenario/run persistence;
- audit ledger and structured JSONL operational events;
- runtime/dependency provenance and source-code fingerprinting;
- structured `/api/v1` contracts with request IDs and security headers;
- health/readiness/about endpoints;
- external CSV/JSON scenario-bundle ingestion;
- Material Circularity Studio NETWORK, PLAN and RUNS workspaces;
- final Constitution compliance evidence;
- project-scoped dependency checks;
- Docker and Render deployment assets;
- full V1 Windows acceptance script.

The accepted Phase-10 computational baseline is preserved. V1 does not add an external LLM dependency and does not require internet access for deterministic decision execution.
