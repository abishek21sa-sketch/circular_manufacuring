# V1.2 — Integrated Decision Workbench

V1.2 is a product/integration release built on the Windows-accepted V1.0.1 baseline.

Highlights:
- coupled stochastic recovery output into IE production/inventory planning;
- coupled IE pack/BOM demand into the critical-material sourcing optimizer;
- coupled AI return state into exact CVRP pickup demand;
- model inventory with variable/constraint counts and verification routes;
- redesigned 100%-zoom Material Circularity Studio;
- actual risk histogram/quantiles instead of anonymous scenario dots;
- readable trace stage selector + payload inspector instead of eleven squeezed JSON columns;
- honest strategy visualization of all six explicit policy scalarizations and nondominated status;
- denser materials/network/plan/routing layouts and larger typography.

The accepted Phase-10 computational core is unchanged.
