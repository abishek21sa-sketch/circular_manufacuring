# Phase 4A — Material Circularity Studio

## Why Phase 4A exists
The original Phase 4 frontend was computationally valid but visually too close to another portfolio engineering workbench. Phase 4A replaces the presentation layer without changing the locked Phase 1–3 AI/IE/OR engines.

## Distinctive interaction model
The studio is a full-screen analytical environment with five modes:

- FLOW — closed-loop physical material canvas with contextual node inspector.
- FRONTIER — full-screen cost/carbon/virgin-material strategy exploration.
- AI / COHORTS — predictive evidence and lifecycle-return interpretation.
- STRESS LAB — scenario controls plus stochastic-futures field.
- EVIDENCE — explicit validation and claims ledger.

The design intentionally avoids:
- left sidebar navigation;
- stacked numbered dashboard sections;
- KPI-card walls;
- factory timeline metaphors;
- machine/WIP state;
- Mission Control terminology.

## Deployment identity
The repository includes a Render Blueprint (`render.yaml`) for a Python web service. Local Windows execution remains the acceptance standard; public deployment occurs only after V1.0/GitHub approval.

## Locked computational boundary
Phase 4A changes presentation and deployment configuration only. Material balances, AI models, MILP formulation, frontier generation, and stochastic simulation remain regression-tested from the previously accepted phases.
